# FruitSnacks — সম্পূর্ণ ই-কমার্স প্ল্যাটফর্ম

> একটি **production-ready, enterprise-grade ই-কমার্স সমাধান** — যেখানে প্রোডাক্ট লিস্টিং থেকে শুরু করে কুরিয়ার ম্যানেজমেন্ট, অ্যানালিটিক্স, পেমেন্ট, কাস্টমার ম্যানেজমেন্ট — সবকিছু এক প্ল্যাটফর্মে।

---

## এক নজরে

FruitSnacks একটি **তিন-স্তর বিশিষ্ট সম্পূর্ণ ই-কমার্স সিস্টেম**:

- 🛒 **কাস্টমার স্টোরফ্রন্ট** — যেখানে গ্রাহক প্রোডাক্ট দেখে এবং অর্ডার দেয়
- 💼 **অ্যাডমিন প্যানেল** — যেখান থেকে পুরো ব্যবসা পরিচালনা করা যায়
- ⚙️ **শক্তিশালী API সার্ভার** — পুরো প্ল্যাটফর্মের কেন্দ্রীয় ইঞ্জিন

প্ল্যাটফর্মটি বাংলাদেশী মার্কেটের জন্য বিশেষভাবে অপ্টিমাইজ করা — Pathao, Steadfast কুরিয়ার ইন্টিগ্রেশন, BulkSMS দিয়ে OTP, এবং BDT কারেন্সি সাপোর্ট নিয়ে।

# 🛍️ কাস্টমার স্টোরফ্রন্ট

আধুনিক, দ্রুত এবং SEO-অপ্টিমাইজড অনলাইন শপ — যা মোবাইল ও ডেস্কটপ উভয়ের জন্য পারফেক্ট।

## হোম পেজ — Drag-Drop Layout Builder

আপনার হোম পেজ সম্পূর্ণ **আপনার নিয়ন্ত্রণে** — Admin → Settings → Home Layout থেকে section drag করে সাজান, যেকোনোটা on/off করুন। কোড ছোঁয়া লাগে না।

### ✨ ২টি হোম ডিজাইন প্রিসেট (একই কোড, ভিন্ন চেহারা)

- **Marketplace প্রিসেট** — অনেক প্রোডাক্টের শপের জন্য: ব্যানার + flash sale + trending/popular/new + category grid + curated strip (নিচের সব section)
- **🆕 Boutique প্রিসেট** — অল্প প্রোডাক্টের (৫–৮টা) premium শপের জন্য: animated **Hero Spotlight** + **Product Features** + **Story Band** storytelling layout — অল্প product-এও পেজ ফাঁকা না লেগে দামি ও আকর্ষণীয় দেখায়

> দুটোই built-in — Admin থেকে এক প্রিসেটের section ON, অন্যটার OFF করে switch করুন।

### হোম পেজের section সমূহ (যেকোনোটা toggle/reorder)

- **ডায়নামিক ব্যানার ও স্লাইডার** — হোম পেজের উপরে আকর্ষণীয় ছবি/অফার স্লাইডশো
- **প্রমোশনাল ঘোষণা বার** — পেজের একদম উপরে rolling announcement (যেমন: "Free Delivery on orders over ৳1000")
- **ফিচার্ড ক্যাটাগরি সেকশন** — আপনার সেরা ক্যাটাগরিগুলো হাইলাইট
- **ফ্ল্যাশ সেল কাউন্টডাউন** — লাইভ টাইমার সহ ফ্ল্যাশ সেল প্রোডাক্ট
- **ট্রেন্ডিং প্রোডাক্ট সেকশন** — যে প্রোডাক্টগুলো এখন বেশি বিক্রি হচ্ছে
- **জনপ্রিয় প্রোডাক্ট** — সবসময় ভালো বিক্রি হওয়া আইটেম
- **নতুন প্রোডাক্ট সেকশন** — সর্বশেষ যোগ করা প্রোডাক্ট
- **ই-কমার্স চয়েস** — কিউরেটেড সেরা পিকস
- **ক্যাটাগরি-ভিত্তিক প্রোডাক্ট গ্রিড** — প্রতিটি ক্যাটাগরির আলাদা সেকশন
- **প্রমোশনাল ব্যানার ও অ্যাড সেকশন** — মার্কেটিং স্পেস
- **🆕 Brand Story সেকশন** — ছবি + গল্প + CTA দিয়ে ব্র্যান্ড পরিচিতি
- **🆕 Reviews Carousel** — গ্রাহক রিভিউ স্লাইডার (auto-featured বা হাতে-বাছাই)
- **🆕 Site FAQ সেকশন** — হোম পেজে সাইট-ব্যাপী সাধারণ প্রশ্নোত্তর
- **🆕 Newsletter সাইনআপ** — ইমেইল/SMS সাবস্ক্রাইব সংগ্রহ
- **ট্রাস্ট কার্ড** — Free delivery, Quality guarantee, Easy return ইত্যাদি দেখানোর সেকশন

প্রতিটি প্রোডাক্টের নিজস্ব ব্র্যান্ডেড অভিজ্ঞতা:

### ✨ Dynamic Product Page System (Premium Feature)

- **প্রতিটি প্রোডাক্টের নিজস্ব থিম** — আলাদা রঙ, ফন্ট, animated floating ছবি
- **Floating fruit images** — পেজের বিভিন্ন সেকশনে যেমন ছবি ভাসমান অ্যানিমেশন
- **৪ ধরনের অ্যানিমেশন স্টাইল** — Float, Spin, Bounce, Sway
- **৩টি স্পিড অপশন** — Slow, Normal, Fast
- **৫টি ফন্ট ফ্যামিলি** — বাংলা ও ইংরেজি উভয়ের জন্য
- **৩টি বাটন স্টাইল** — Filled, Outlined, Gradient
- **প্রতি প্রোডাক্টে theme override** — চাইলে নির্দিষ্ট প্রোডাক্টে কালার পরিবর্তন

### প্রোডাক্ট ডিটেইল সেকশন

- **মাল্টি-ইমেজ গ্যালারি** — একাধিক ছবি + জুম ফিচার + প্রোডাক্ট ভিডিও সাপোর্ট
- **প্রাইস ডিসপ্লে** — discount price, line-through original price, ক্যাম্পেইন প্রাইস
- **ভ্যারিয়েশন সিলেক্টর** — সাইজ, কালার, প্যাক ভিন্নতা (যেমন: 500g, 1kg, 2kg)
- **স্টক ইনডিকেটর** — "Only 3 left" type alerts
- **Quantity selector** — কয়টা কিনবেন
- **Add to Cart / Buy Now** বাটন
- **Wishlist বাটন** — পছন্দের প্রোডাক্ট সেভ
- **Quick share বাটন** — সোশ্যাল মিডিয়ায় শেয়ার

### প্রোডাক্টের সম্পূর্ণ তথ্য

- **Short description** — হিরো সেকশনে দ্রুত পরিচিতি
- **Badge** — "NEW", "BESTSELLER", "ORGANIC" ইত্যাদি লেবেল
- **Long description** — Rich text এডিটর দিয়ে format করা বর্ণনা
- **Short features** — আইকন সহ মূল বৈশিষ্ট্য (max 4)
- **Process steps** — "How it's made" type ধাপ
- **Benefits list** — বুলেট পয়েন্টে উপকারিতা
- **Use cases** — আইকন সহ ব্যবহারের পরামর্শ
- **Nutrition information** — প্রতি serving-এ calories, protein, carbs, fiber, sugar, fat, vitamins, iron, calcium, origin, shelf life, certifications
- **Product FAQ** — প্রোডাক্ট-নির্দিষ্ট প্রশ্নোত্তর

### Right Side Shopping Section

- **রিভিউ ছবি আপলোড** — গ্রাহকরা রিভিউতে ছবি যোগ করতে পারবে

## শপিং কার্ট সিস্টেম

আধুনিক dual-storage কার্ট সিস্টেম যা guest user-দেরও সেবা দেয়:

- **Guest cart** — লগইন ছাড়াই কার্টে প্রোডাক্ট যোগ করার সুবিধা (browser-এ সেভ)
- **Logged-in cart** — ডেটাবেসে সেভ, যেকোনো device থেকে access
- **Auto-sync after login** — guest cart + database cart মার্জ
- **Real-time price calculation** — quantity change-এ instant total update
- **Variation support** — same product-এর different variants একসাথে
- **Quantity adjustment** — +/- বাটন বা direct input
- **Stock validation** — স্টকের বেশি যোগ করতে দেয় না
- **Item removal** — individual বা পুরো কার্ট ক্লিয়ার
- **Cart summary widget** — navbar-এ সব সময় কার্ট কাউন্ট

### কুপন সিস্টেম

- **কুপন কোড অ্যাপ্লাই** — checkout-এর আগে validate
- **২ ধরনের ডিসকাউন্ট:**
  - Fixed amount (যেমন: ৳100 off)
  - Percentage (যেমন: 15% off, optional max cap সহ)
- **কুপন স্কোপ:**
  - All products
  - Specific products
  - All customers
  - Specific customers (loyalty program)
- **Usage limit** — প্রতি কাস্টমার এবং মোট কতবার ব্যবহার যাবে
- **Expiry date** — কুপন end date

## ক্যাম্পেইন ও অফার সিস্টেম

মার্কেটিং-এর শক্তিশালী টুল:

### ক্যাম্পেইন (Marketing Campaigns)

- **নির্দিষ্ট সময়ের ক্যাম্পেইন** — শুরু ও শেষের তারিখ
- **Multiple products one campaign-এ** — একসাথে অনেক প্রোডাক্ট
- **ডিসকাউন্ট:** Fixed amount বা Percentage
- **লাইভ কাউন্টডাউন টাইমার** — কতক্ষণ বাকি
- **ক্যাম্পেইন ডিটেইল পেজ** — সব ক্যাম্পেইন প্রোডাক্ট একসাথে

### Flash Sale

- **হোম পেজে highlighted section**
- **Live countdown timer**
- **Auto-managed via campaigns**
- **Special pricing badge** — flash sale price clearly visible

## গ্রাহক অ্যাকাউন্ট

- **"To Be Reviewed" tab** — যেসব order delivered কিন্তু review বাকি
